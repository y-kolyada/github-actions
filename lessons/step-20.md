**Дата:** 2026-10-21. **Исполнитель:** Antigravity. **Основание:** решение Архитектора (`ik`, указание в чате: «Словарь понятий появился - принято. ## Хочу

Внедрить интерактивную семантическую разметку терминов (`.term` / `.term-btn` / `.term-card`) на всех страницах курса в секциях их первого упоминания («Где встретилось впервые»), замкнув двустороннюю интерактивную связь между основным текстом глав и Словарём понятий (`ru/glossary.html`).

При чтении глав читатель должен видеть выделенный термин с пунктирным подчеркиванием, иметь возможность кликом открыть всплывающую карточку с кратким определением и перейти по ссылке в полный Словарь понятий. При переходе из Словаря по ссылке «Где встретилось впервые» читатель попадает в точный контекст раздела, где термин выделен и готов к открытию.

Разметка охватывает все 28 терминов словаря в 11 главах курса (`01.html`, `02.html`, `03.html`, `04.html`, `05.html`, `06.html`, `07.html`, `08.html`, `09.html`, `11.html`, `12.html`). Каждая интерактивная карточка оформляется строго по стандарту Simple Web Architecture: контейнер `.term`, кнопка `.term-btn` с атрибутом `aria-expanded="false"`, всплывающее окно `.term-card` с атрибутом `hidden`, заголовком, кнопкой закрытия `.term-close`, лаконичным определением и блоком `.term-links` со ссылкой на `glossary.html#term-*`.

## Предикаты

1. **Разметка терминов в тексте глав:** Во всех целевых секциях первого появления 28 понятий Словаря в 11 главах курса внедрена каноническая интерактивная разметка `.term > .term-btn + .term-card`. Каждая карточка содержит доступный заголовок, кнопку закрытия, определение и ссылку на соответствующий якорь `glossary.html#term-*`.
2. **Связность и проверка целостности ссылок:** Все ссылки из карточек терминов ведут на существующие якоря `ru/glossary.html`; `python3 tools/check-links.py` возвращает код 0 при нуле битых ссылок; `python3 tools/build-meta.py --check` и `python3 tools/build-nav.py --check` подтверждают консистентность метаданных и навигации.
3. **Интегральные проверки:** `git diff` строго в границах задачи; все утверждения сайта в `tools/claims.tsv` зелёные; полный проверочный контур `./check.sh` выводит `ЗЕЛЁНОЕ` (9/9 проверок успешны, мобильный телефон 390px чистый, десктопная панель 860px/1400px чистая, длинных тире нет).
