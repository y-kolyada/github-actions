## Хочу

Практический раздел 11: **«Примеры: командный конвейер, релизы и поставка (Pro)»** (`ru/11.html`) на русском языке. Раздел ориентирован на практику инженера в продуктовой команде и охватывает реальные сценарии непрерывной доставки (CD), управления релизами, многоконтурных развертываний и оптимизации производительности конвейера.

Материал строится по канонической структуре практических разборов: 6 детальных задач с законченными рабочими YAML-пайплайнами и блоками объяснения внутренней механики рантайма («Почему так» в `div.prints`). Разбор охватывает оптимизированную сборку Docker-образов с публикацией в GHCR и кэшированием слоев через GitHub Cache backend (`type=gha`), автоматизацию семантического версионирования и генерацию GitHub Release, современный безопасный деплой статических сайтов на GitHub Pages с минимальными точечными `permissions`, конвейер продвижения по окружениям (Staging -> Production) с ручным подтверждением через Environment Protection Rules, подавление избыточных очередей сборки через группы `concurrency` с `cancel-in-progress`, а также динамическую генерацию матриц тестирования из JSON-выхода предшествующей задачи.
